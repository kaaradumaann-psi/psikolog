# Kapsam

Bu depo psikolog çalışma alanıdır.

Dahil:

- Bugünkü seans hazırlığı ve dikkat listesi
- Danışan, anamnez, 4P formülasyon, tedavi hedefi, güvenlik planı
- SOAP, randevu, görev, not, belge
- BDI, BAI, SCL-90-R, GAD-7, PHQ-9 izlemi
- Kayıtlardan doldurulan ilerleme raporu
- KVKK yedek, yerel denetim izi, isteğe bağlı Supabase RLS

Ölçek puanı tanı değildir. Güvenlik maddesi pozitifse karar görüşmeye aittir.
